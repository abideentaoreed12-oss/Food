# Veyrang — Premium Food Delivery Platform

> Veyrang — High-performance multi-restaurant food delivery platform with live GPS doorstep tracking, customizable menus, Nigerian payment channels, and dedicated kitchen and rider portals.

## 🚀 Key Features

- **Storefront & Discovery**: Real-time kitchen discovery across Lagos & Abuja delivery zones with category filters, ratings, and instant search.
- **In-App Veyrang Wallet**: Integrated digital wallet with privacy balance toggle, instant top-up via Paystack debit cards, Providus Bank virtual account transfer, and USSD.
- **Order Tracking & Live Status**: Step-by-step dispatch workflow (Placed → Kitchen Prep → In Transit → Delivered) with ETA calculations.
- **Multi-Role Portals**:
  - 👤 **Customer**: Discovery, custom item modifications, cart management, address book, wallet, and order tracking.
  - 🍳 **Merchant Kitchen (KDS)**: Real-time ticket management, prep time adjustments, and ticket printing.
  - 🛵 **Rider Dispatch**: Route progression, GPS pickup, delivery navigation, and earnings tracking.
  - 🛡️ **Admin Operations**: Platform oversight, delivery zone pricing, commission rates, and dispute resolution.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide React, Motion
- **Backend / API**: Express, Node.js, JWT Authentication
- **Build Tool**: Vite

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

The application will be available at `http://localhost:3000`.

### 3. Build for Production
```bash
npm run build
```
